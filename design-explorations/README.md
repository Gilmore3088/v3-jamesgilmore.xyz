# Design explorations

Three simple homepage options for jamesgilmore.xyz: Warm (A), Photo-led (B), and Classic (C).
They are not wired into the Next.js app; they exist to choose a direction.

Serve locally:

```bash
cd design-explorations
python3 -m http.server 8080
# or: npx serve .
```

Then open http://localhost:8080 and pick an option from the index.
